    OpenF1Client ¶

    Cliente da API OpenF1.

    Faz novas tentativas com backoff exponencial em respostas 429/5xx, timeouts e falhas de conexão, e respeita um intervalo mínimo entre requisições.

    Parameters:

    Name Type Description Default
    base_url str

    URL base da API (ex.: https://api.openf1.org/v1).

    		 required
    timeout float

    Timeout de cada requisição, em segundos.

    		 30
    max_retries int

    Número de novas tentativas após a primeira falha transitória.

    		 3
    min_interval float

    Intervalo mínimo entre requisições, em segundos.

    		 0.5
    backoff_factor float

    Base do backoff; a espera é backoff_factor * 2**tentativa.

    		 1.0
    session Session | None

    requests.Session a reutilizar; se omitida, uma nova é criada.

    		 None
    Example

    with OpenF1Client("https://api.openf1.org/v1") as client: # doctest: +SKIP ... client.get("sessions", {"year": 2024})
